# Original IP Character Designer

一套帮助创作者设计原创角色 IP 的中文 Agent Skill。它从用途、受众和载体出发，引导使用者选择视觉风格与配色，再整理成可复用的角色设定。它不是现成角色图库，也不保证自动生成图片。

## 它能做什么

- 用五张风格卡（极简线描、几何现代、复古拼贴、柔和手作、编辑插画）比较线条、形状、质感、情绪和不适用场景。
- 从五组双色、三组三色中选择配色；每组附精确 HEX、用途和建议比例。可查看[可视色卡](original-ip-character-designer/assets/palette-swatches.svg)。
- 提出原创角色概念，并在使用者确认后形成角色设定手册和生图提示词。
- 有生图工具且使用者要求时，尝试生成并检查首张草图；没有工具时明确只交付文字设定。

## 安装与使用

将 [`original-ip-character-designer/`](original-ip-character-designer/) 整个文件夹放进支持 Agent Skills 的工具的技能目录。例如 Codex 用户可放进 `~/.codex/skills/`，然后在新对话中说：

> 请使用 original-ip-character-designer，帮我设计一个用于虚构读书社群头像的原创角色。

只复制 `SKILL.md` 会缺少风格卡、色板和模板；请保留整个文件夹结构。开始时只需提供用途、受众和希望传达的感觉；不必上传真人照片。

## 一个虚构示例

假设要为“云朵烘焙屋”设计小狐狸角色。Skill 会先确认头像与纸袋印刷的限制，再推荐最多三张风格卡及对应色板，让使用者选择；确定方向后，才输出稳定的轮廓、配色规则和角色设定。详见[全虚构案例](original-ip-character-designer/examples/fictional-briefs.md)。
