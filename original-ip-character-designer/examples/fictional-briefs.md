# 全虚构试用案例

这些案例只用于测试 Skill，不代表真实品牌、客户或活动。

## 案例一：信息很少的烘焙角色

“我开了一家虚构的云朵烘焙屋，想设计一个温暖的小狐狸角色，用在头像和纸袋上，但我不会描述风格和颜色。”

期望检查点：先问目标受众和纸袋印刷限制；最多推荐三张风格卡并给出准确色板编号、HEX 与比例；不未经选择就把角色定稿；没有生图工具时交付可用提示词。

## 案例二：约束较多的科学社角色

“给虚构的小星球科学社设计一个机器人角色，用于头像和活动海报。要有趣但不幼稚；希望紫色和深蓝色，预算有限，不要像任何现有动画角色。目前没有生图工具。”

期望检查点：推荐符合紫与深蓝的 B5 等色板，并解释印刷与小尺寸识别；提出有独立轮廓的原创概念；在工具缺席时不声称已生成图片。
