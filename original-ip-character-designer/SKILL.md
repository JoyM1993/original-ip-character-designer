# 原创 IP 角色设计

帮助使用者从用途出发做出自己的角色，而不是复制已有形象。适用于头像、内容栏目、活动或产品吉祥物；不用于照搬现有角色、艺术家的标志性画风，或未经授权处理他人的肖像。

## 开始前

确认用途、受众、出现在哪些载体、希望传达的性格，以及必须保留／避免的元素。信息少时只问决定下一步所必需的问题。真人照片不是必需输入；如需把它交给外部生图工具，先说明用途并取得当次同意，不把照片写进可分享的文件。

## 做出可见的选择

先读 [五张风格卡](references/style-cards.md)，根据用途推荐最多三张，并说清各自不适合的情况。结合 [八组色板数据](references/palettes.json) 与 [可视色卡](assets/palette-swatches.svg)，展示每张卡推荐的三个色板编号、精确 HEX、各色角色及比例。双色关系保持双色，三色关系保持三色；黑白文字可作为提高可读性的功能色。请使用者确认一张风格卡和一组色板后再定稿。若已有品牌色，说明如何有限调整，不悄悄覆盖使用者的选择。

## 从概念到定妆

给出两到三个轮廓与识别点明显不同的原创概念，解释它们在小头像和主要使用载体中的表现。请使用者选择或修改。用 [角色设定手册模板](templates/character-bible.md) 固定比例、特征、表情、姿态、配色角色、允许变化和禁止事项，并附一条可迁移的生图提示词。

有生图工具且使用者要求出图时，按确认的设定生成一张 1:1 定妆草图，然后做一致性检查：对照手册核对轮廓、识别点、颜色和气质；只修改实际偏差。没有生图工具或工具失败时，交付完整文字设定与提示词，明确说明“没有生图工具，尚未生成图片”。不得把占位图称为成品。

若使用者要求像某个现有角色或艺术家的特有画法，先解释可借鉴的高层次属性，再提出有区别的原创方向。最终交付区分“使用者已确认”和“仍待确认”，不保证生成图已完成法律清权或绝对独创。需要试跑时可读 [全虚构案例](examples/fictional-briefs.md)。
